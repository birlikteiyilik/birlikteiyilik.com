`turkey-locations.json` contains the province and district names used by the application forms. It is a compact, Turkish-title-cased copy of the 81-province / 922-district dataset published by [CityDistrictJSONAPI](https://github.com/mertmtn/CityDistrictJSONAPI), whose source data was retrieved from Türkiye's Ministry of Interior e-İçişleri administrative divisions page.

The forms load this local file so province and district selection does not depend on a third-party service at submission time.
